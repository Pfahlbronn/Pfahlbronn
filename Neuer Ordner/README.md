# Pfahlbronn entdecken

Eine kleine responsive Website über Pfahlbronn.

## Lokal testen
Einfach `index.html` im Browser öffnen.

## Kostenlos mit GitHub Pages veröffentlichen
1. Erstelle ein öffentliches Repository namens `DEINBENUTZERNAME.github.io`.
2. Lade alle Dateien dieses Ordners hoch.
3. Gehe in **Settings → Pages**.
4. Wähle **Deploy from a branch**, Branch `main`, Ordner `/ (root)`.
5. Nach der Veröffentlichung ist die Seite unter `https://DEINBENUTZERNAME.github.io/` erreichbar.

## Inhalte anpassen
Die Beispielkarten und Texte in `index.html` sind bewusst leicht zu ändern. Eigene Bilder kannst du in `images/` ablegen und die `background`-Angabe in `style.css` anpassen.
