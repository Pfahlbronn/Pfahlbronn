# Pfahlbronn – Website

## Online stellen mit GitHub Pages
1. Repository erstellen: `DEINBENUTZERNAME.github.io`
2. Alle Dateien aus diesem Ordner hochladen.
3. GitHub: **Settings → Pages → Deploy from a branch → main → / (root) → Save**
4. Website öffnen: `https://DEINBENUTZERNAME.github.io/`

Die Seite ist eine statische HTML/CSS/JS-Website und benötigt keinen Server.
